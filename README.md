# sales-performance-dashboard
Dashboard web: https://claudioaz.github.io/sales-performance-dashboard/


Dashboard interativo de análise de vendas de 2020, desenvolvido com HTML, CSS e JavaScript, com indicadores de desempenho (KPIs), gráficos dinâmicos e filtros interativos para análise de receita, produtos, vendedores, filiais, descontos e tendências de vendas.
